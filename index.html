The missing translation layer

You don't need to be an engineer. You need a translator.

Any AI coding agent — Claude Code, Cursor, Copilot, and the rest — understands your plain English fine. That direction was never the hard part. It's the direction coming back that breaks: the reply arrives in engineer, like

Natural language is meant to work in both directions. Right now it only works on the way in. This translates the way back too — the status update, the error, the question — so the whole conversation stays in words you can act on.

Every word of that sentence means something specific and simple. Nobody ever told you what. This is where they tell you.

And it keeps growing on its own: agents running these instructions file the words they had to explain, so the dictionary fills in from real confusion rather than guesswork. You can flag one yourself at the bottom — the word alone is enough.

Make your agent talk like this

A dictionary helps when you already know which word to look up. Better is an agent that never makes you look one up. These are plain instructions — no install, no account, nothing tied to one tool. Paste them into your agent and tell it you are not an engineer.

Where to paste them, per tool

Works in Claude Code, Cursor, Copilot, Windsurf, Gemini, ChatGPT, Lovable, Replit, Bolt — anywhere there is a chat box or a rules file. The longer version, and the one-line-per-tool instructions, are on GitHub.

Can’t install anything where you are building? Then use the three questions. They need no setup at all.

Flag a word

Hit a word that stopped you and it’s not in here? The word on its own is the whole contribution — you do not need to know what it means. That’s rather the point. If enough people flag the same one, it gets written up and added.

Nothing is sent automatically. This writes the text for you and opens GitHub, where you press Submit yourself.
